# UI design system

Neutral surfaces + vivid accents. One spacing rhythm, one card language,
one icon language — every screen is measured, not eyeballed.

## Spacing tokens

Single source: `res/values/dimens.xml` (XML) and `ui/theme/SceneDimens.kt`
(Compose). Values mirror each other; keep both in sync.

| Token | Value | Used for |
|---|---|---|
| `space_xs/s/m/l/xl/xxl` | 4 / 8 / 12 / 16 / 24 / 32 dp | every padding & gap |
| `screen_h` | 16dp | screen content edge (all screens) |
| `screen_v_top` / `screen_v_bottom` | 12 / 24 dp | scroll start / end |
| `card_gap` | 12dp | gap between cards |
| `card_padding` | 16dp | card inner padding |
| `row_min_height` | 48dp | single-line setting rows |
| `icon_size` / `icon_gap` | 24 / 16 dp | row icons |

Rules:

- Padding/margin values live on the 4dp grid only: no 5/6/7/9/10/11/14/15dp.
- Content starts at **16dp** from the screen edge; inside a card it lands at
  **32dp** (16 screen + 16 card padding).
- Text sizes are in **sp** (never dp) so font scale works.

Verify with `tools/ui-padding-check.sh` (uiautomator bounds → dp table; the
dominant row insets must be 16 or 32).

## Cards & components

| Piece | Spec |
|---|---|
| `ListCardItem` / `InCardListItem` (XML) | 16dp radius, `?cardBg` surface, 16dp padding, 12dp gaps |
| `bg_card_plain` / `bg_card_clickable` | shared card drawables (radius 16) |
| `SceneButton` | pill (`bg_button_pill`), min 88×40dp, 13sp, single line |
| `SceneRow` conventions | 48dp min height, icon 20–24dp, value right-aligned |
| Compose | `SceneDimens` + Miuix `Card(...)` with `insideMargin = 16dp` |

## Profile card (Tuner)

One card answers "what may Scene do right now":

- title **Profile** + the engine master switch;
- source caption (`Tuning JSON · sm6150`) — tap opens the tuning-source dialog
  (explain / open folder / remove `/data/powercfg.sh`);
- one row per profile: icon, name, `ProfileSummary` caps ("1.32 / 1.32 GHz ·
  UFS save · GPU ≤ p5"), `Modified` chip when it differs from the preset, check
  when active;
- **TRUE OFF** row in the same card (it is the stronger switch).

## Profile editor (CPU control)

- banner (what is edited / read-only reason), profile chips, live-state card
  (current frequencies, load, temperature), then one card per group:
  CPU clusters, CPU boost, GPU, cpusets, scheduler, cores, thermal/memory/storage;
- rows are 48dp: title left, accent value right, `●` when changed vs preset;
- switches for booleans, number dialog for thresholds, pickers for frequencies
  / governors / cpusets;
- Save + Reset to preset live in the last card; a running profile locks the
  editor (TRUE OFF opens it read-only).

## Colors

`res/values/colors.xml` is the palette source; `ui/theme/SceneTheme.kt`
mirrors it for Compose.

- **Surfaces stay neutral**: light `#F2F2F2/#FFFFFF`, dark `#000000/#1A1A1A`.
- **Accent (interactive)**: violet — light `#7C3AED`, dark `#A78BFA`
  (`scene_accent_*`, `?attr/colorAccent`, `SceneTheme.primary`).
- **Mode identities**: power save `#60A5FA`, balance `#34D399`,
  performance `#A3E635`, custom `#FBBF24` (`color_*`, `*_bg` for the cards).
- **Utilization ramp**: `#34D399 → #A3E635 → #FBBF24 → #F43F5E`.
- **Pastels for minor labels**: `pastel_*` (see `ScenePalette.kt`).

## Icons

All raster icons (131 PNGs) are generated by `tools/gen-icons-bold.py`:
each icon keeps its silhouette (alpha) and receives a category duotone
gradient + bright highlights. Categories are filename-driven (mode icons,
battery, storage, process, freeze, files, power, utilities).

```bash
python3 tools/gen-icons-bold.py   # regenerate every PNG icon in place
```

Vector drawables keep their `?android:colorAccent` / inline tint so they
follow the theme automatically.

## Verifying a screen

```bash
bash tools/ui-padding-check.sh --rows   # insets + row heights of current screen
```

Screenshot sweep for the record: `bash tools/ui-map.sh [screen]` (see
`docs/UI-MAP.md`).
